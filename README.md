## Present

Open the GitHub Pages link. Use Page Down / Page Up or arrow keys with a presentation clicker. Press **P** for a separate presenter window, **F** for fullscreen, **O** for the outline, and **?** for controls. Browser fullscreen availability varies; F11 is an alternative.

The white web presentation loads its figures from the assets folder for faster loading. A standalone offline HTML copy is maintained in the authoring workspace. Thai uses embedded DB Helvethaica X. English requests locally installed Neue Haas Grotesk Text Pro, with embedded Helvetica as fallback.

The Logic Model workshop adapts the W.K. Kellogg Foundation Logic Model Development Guide (January 2004). Workshop step numbering, exercises, timing and hypothetical nicotine-policy examples are adaptations. The hypothetical examples do not report policy effectiveness. References and source boundaries appear in presenter notes and the reference appendix.
